Thumbnail Maker Guide

1

Build Your Scene

Add assets like Characters, Blocks, Items, or Text using the bottom toolbar. Choose from custom presets or your own saves.

2

Arrange & Depth Control

Drag assets to position them. Use the left Layers panel to drag rows up/down to change order, or drag items inside character layers to make them hold objects!

3

Fine-Tune Properties

Select any item to access the Properties panel on the right. Modify its scale, rotation, opacity, filters (neon glow, blur), or add custom facial expressions!

Please Rotate Your Device

This website is optimized for landscape mode. Rotate your device to horizontal to continue using the planner and editor.

Many features will be buggy and not work as intended when using vertical view.
